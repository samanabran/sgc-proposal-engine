# Evidence File Standard

Every client folder accumulates an evidence file across the deal
lifecycle — not a separate document, but this checklist applied against
what's already in `00-intake/`, `02-calc/`, `03-draft/`/`05-issued/`, and
`04-review/`. Complete before go-live sign-off (G29).

- [ ] `00-intake/verbal-promises.md` exists and every entry is classified
      PRICED / DEFERRED / EXCLUDED
- [ ] `00-intake/client-brief.yaml` complete, including risk-assessment
      inputs
- [ ] `02-calc/pricing-worksheet.yaml` complete, all three exposures
      computed (G21)
- [ ] `02-calc/gate-report.md` shows all 41 gates evaluated with a
      recorded result
- [ ] `07-protection/walkaway/deal-card.template.md` copy completed and
      dated, showing it preceded the first pricing conversation (G22)
- [ ] Every concession, if any, logged in `manifest.yaml: escalations`
      with its compensators per `concession-ladder.yaml` procedure (G14)
- [ ] `04-review/qa-checklist.md` and `04-review/brand-qa-checklist.md`
      both complete
- [ ] Signed proposal (or documented verbal acceptance with a written
      follow-up confirmation) on file
- [ ] Any clause used from the library that carries
      `requires_counsel_review: true` shows a logged counsel review, not
      just the draft text

An incomplete evidence file blocks go-live sign-off — this is what makes
a dispute defensible later, not a formality to skip under deadline
pressure.
