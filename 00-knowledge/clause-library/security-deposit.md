# Clause: Security Deposit

**Purpose**: document a cash security deposit where the risk band or
cadence requires one (`risk-security-matrix.yaml`, `payment-plans.yaml`).

**requires_counsel_review**: true.

> **DRAFT FOR COUNSEL REVIEW.** Do not include in an issued proposal until
> reviewed by UAE counsel. Enforceability of deposit-holding, refund
> timing, and set-off rights varies.

**When mandatory**: any deal where the risk band or cadence table
specifies a `deposit_1_month` or `deposit_2_months` instrument.

**When it must NOT be used**: never combine with a description implying
the deposit is non-refundable — deposits are held security, not a fee.

---

## Draft text (pending counsel review)

> The Client provides a security deposit equal to [1/2] month(s) of the
