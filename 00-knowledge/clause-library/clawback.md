# Clause: Clawback

**Purpose**: protect the unrecovered build principal if a client
terminates early. This is the mechanism behind G4/G16 — no deferred
structure exists without it, and no approver may waive it.

**requires_counsel_review**: false.

**When mandatory**: any structure where build value is deferred rather
than paid in full at kickoff (i.e. `mobilisation_aed < build_value_aed`).

**When it must NOT be used**: never omit on a deferred structure — there
is no discretionary case for leaving this out.

---

## Approved verbatim text

> If this subscription is terminated before the end of the committed term
> for any reason other than SGC TECH AI's material breach, the unrecovered
> balance of the implementation value becomes immediately due and payable.
