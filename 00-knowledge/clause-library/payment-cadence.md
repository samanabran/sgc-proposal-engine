# Clause: Payment Cadence

**Purpose**: state whichever cadence was selected from `payment-plans.yaml`
plainly, including the security instrument it carries, if any.

**requires_counsel_review**: false.

**When mandatory**: every proposal — the cadence is always stated
explicitly, never left implicit as "monthly."

**When it must NOT be used**: never state a cadence more favorable to the
client than `payment-plans.yaml: min_cadence_current` (quarterly in
advance) without the sign-off that cadence requires — see G33.

---

## Approved verbatim text (fill from the selected cadence)

> Subscription fees are billed [cadence] in advance. [If security
> applies:] This cadence is supported by [security instrument, plain
> language — e.g. "a one-month security deposit, refundable at the end of
> the term subject to the terms below"].
