## 1. Objective

We are looking for a simple, easy-to-use CRM and ERP system for a real estate brokerage company. The system should help agents, admin, and management work in one organized platform without complicated steps.

## 2. Main System Requirements

- Easy to use for agents, admin, managers, and CEO.
- Can be used on desktop.
- Includes CRM, agent KPI, admin tools, listing management, basic ERP, and reports.
- Can be customized based on our company requirements.
- Allows data export to Excel when needed.
- Includes training and support for the team.

## 3. CRM Requirements

The CRM should help agents manage leads, clients, follow-ups, and deals in a simple way.

| Requirement | Purpose | Priority |
|---|---|---|
| Lead Management | Add and track buyers, sellers, landlords, tenants, and investors. | Must Have |
| Client Database | Store client name, phone number, email, budget, property interest, and status. | Must Have |
| Follow-up Reminders | Remind agents to call, message, or follow up with clients. | Must Have |
| Deal Pipeline | Track clients from inquiry to viewing, negotiation, and closing. | Must Have |
| Meeting Tracker | Record client meetings completed by each agent. | Must Have |
| Referral Tracker | Record referrals received by each agent. | Must Have |
| Listings Tracker | Record listings added by each agent. | Must Have |
| Deals Tracker | Record closed deals and transaction status. | Must Have |
| WhatsApp / Email Integration | Communicate with clients faster and keep follow-up records. | Must Have |
| Mobile Access | Agents can update their activities from their phones. | Must Have |

## 4. Agent KPI Tracking

The KPI dashboard should be simple and focused only on the main activities.

| Requirement | Purpose | Priority |
|---|---|---|
| Meetings | Number of meetings completed per agent. | Must Have |
| Referrals | Number of referrals received per agent. | Must Have |
| Listings | Number of listings added per agent. | Must Have |
| Deals | Number of closed deals per agent. | Must Have |
| Daily Activity View | View today's performance and activities. | Must Have |
| Monthly Summary | See monthly totals, target versus actual, and team ranking. | Must Have |
| Charts / Dashboard | Simple graphs for management review. | Must Have |

## 5. Admin Requirements

| Requirement | Purpose | Priority |
|---|---|---|
| Attendance Tracker | Agents can be marked Present, Late, or Absent. Late and Absent must include a reason. | Must Have |
| Employee Records | Store agent/staff details, joining date, position, contact details, and documents. | Must Have |
| Document Management | Upload and organize contracts, IDs, agreements, NOCs, property documents, and KYC forms. | Must Have |
| Task Management | Assign tasks and follow up on pending work. | Must Have |
| Calendar | Track meetings, viewings, interviews, trainings, and company events. | Must Have |
| Approval System | Manager/CEO approval for important requests, commissions, allowances, and documents. | Must Have |
| Internal Notes | Add notes for agents, clients, listings, and deals. | Must Have |

## 6. Listing Management

| Requirement | Purpose | Priority |
|---|---|---|
| Property Details | Record area, price, size, bedrooms, bathrooms, property type, and status. | Must Have |
| Owner Details | Record seller or landlord information. | Must Have |
| Listing Status | Available, rented, sold, reserved, inactive, or pending. | Must Have |
| Permit Tracking | Track permit number and expiry date. | Must Have |
| Photos and Documents | Upload property photos, title deed, NOC, floor plan, and other files. | Must Have |
| Agent Assignment | Assign each listing to a specific agent. | Must Have |
| Portal Tracking | Track listings posted on Property Finder, Bayut, Dubizzle, website, or social media. | **Nice to Have** |

## 7. ERP / Management Requirements

| Requirement | Purpose | Priority |
|---|---|---|
| Company Dashboard | Overview of leads, listings, deals, revenue, and agent performance. | Must Have |
| Commission Tracking | Calculate agent and company commission split. | Must Have |
| Revenue Report | Track company income from closed deals. | Must Have |
| Expense Tracking | Track basic office, admin, and marketing expenses. | **Nice to Have** |
| Payroll Support | Record salary, allowance, deductions, and commission payouts. | **Nice to Have** |
| Reports | Daily, weekly, and monthly reports for management. | Must Have |
| User Roles | Access levels for Agent, Admin, Manager, and CEO. | Must Have |

## 8. System Preference

- The system should be simple and not complicated for agents.
- The dashboard should be clean and easy to understand.
- Management should be able to check performance quickly.
- The system should not require too many clicks for daily updates.
- The provider should offer setup assistance, training, and after-sales support.
- The price should be affordable and suitable for a real estate brokerage team.
