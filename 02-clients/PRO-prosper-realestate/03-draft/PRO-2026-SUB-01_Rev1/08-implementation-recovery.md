# Implementation Timeline

## Phases

| Phase | Weeks | Key activities |
|---|---|---|
| Discovery | 1–2 | Requirements confirmation, data audit against 500-record migration scope |
| Build | 3–4 | Property/tenancy/CRM/invoicing configuration, user role setup |
| UAT + Go-Live | 5–6 | UAT with Dian Sajulga, two training sessions, go-live |
| Hypercare | 7–10 | Daily support, adoption coaching, day-30 activity threshold check (§09) |

Go-live target: 4–6 weeks from kickoff. Each stage has a defined exit
criterion before the next begins.

## Replacing current tooling

Spreadsheet-based tracking and WhatsApp-only client communication logging
are retired at go-live for the workflows this proposal's scope covers, not
run in parallel indefinitely — a defined cutover date is agreed during
Discovery. Attendance tracking and payroll continue on the Client's
existing process, unchanged by this proposal (see §07).
