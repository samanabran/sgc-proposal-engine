# Current Process Assessment (As-Is)

| Observed gap | Implied business impact |
|---|---|
| No centralized lead or client record | Leads and client history scattered across agent phones, WhatsApp, and spreadsheets |
| No unified listings register | Property and permit data tracked inconsistently, risking compliance gaps |
| No structured KPI visibility | Management cannot see agent performance without manual collection |
| Manual attendance tracking | Paper- or spreadsheet-based, creating administrative overhead — no system solution proposed here, see §07 |
| No connected reporting layer | Reports require manual compilation rather than direct system generation |
| No accounts/invoicing system | Basic financial record-keeping handled outside any structured platform |

These gaps are not unusual for a growth-stage brokerage, and they were
raised directly by the client (via CRM's logged BANT need items and the
prior requirements exchange): field customization needs, no-extra-cost
lead management, multiple admin access levels, attendance tracking,
accounts integration including salary structure, and AI/ChatGPT
integration. This proposal maps each item to a specific classification —
priced, deferred, or not currently priceable — in §07, rather than
implying every gap is addressed by the base scope in §06.
