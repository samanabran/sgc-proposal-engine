# Future State Vision (To-Be)

The future state replaces today's fragmented spreadsheet/WhatsApp tooling
with one connected operating platform for the parts of the business this
proposal's base scope covers: every lead, every listing, and every
invoice lives in one place, with role-based access separating agents,
admins, and management.

- A single contact record per buyer, seller, landlord, tenant, and
  investor, with customizable fields.
- A unified property/unit register replacing inconsistent listing
  tracking.
- Centralized CRM pipeline with source attribution and lead management
  that does not carry an additional-user surcharge for the team as
  currently sized.
- Role-based access for multiple admins, distinguishing agent, admin, and
  management visibility.
- TRN-compliant invoicing tied to the underlying deal record.
- A reporting layer producing views from live data, replacing manual
  compilation.
- A foundation ready for portal-sync and AI-lead-scoring add-ons (§07)
  once this core layer is proven in use.

**What this vision deliberately does not include**: attendance/check-in
tracking, payroll/salary/WPS processing, and a general-purpose AI
assistant remain outside this proposal entirely — not deferred to a
priced Phase 2, but genuinely unpriced pending a knowledge-layer scoping
exercise this document does not attempt (see §07). Mobile access is
delivered via a fully responsive browser experience, covering day-to-day
lead and visit updates from any device.
