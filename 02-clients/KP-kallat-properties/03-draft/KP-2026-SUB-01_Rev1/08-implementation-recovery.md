# Implementation Timeline

## Phases

| Phase | Weeks | Key activities |
|---|---|---|
| Discovery | 1–2 | Requirements confirmation, data audit against 500-record migration scope |
| Build | 3–4 | Property/tenancy/CRM/accountability configuration, agent role setup |
| UAT + Go-Live | 5–6 | UAT with Sadique Abbas, two training sessions, go-live |
| Hypercare | 7–10 | Daily support, adoption coaching, day-30 activity threshold check (§09) |

Go-live target: 4–6 weeks from kickoff. Each stage has a defined exit
criterion before the next begins.

## Replacing current tooling

Zapier-based lead distribution and Google Sheets reporting are retired at
go-live, not run in parallel indefinitely — a defined cutover date is
agreed during Discovery so agents are not working across two systems for
an extended period. Manual portal posting to Bayut, Property Finder, and
Dubizzle continues as-is until portal sync (§07, separately priced) is
added.
