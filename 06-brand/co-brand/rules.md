# Co-Brand Rules

When a client asks for their own brand to appear alongside SGC's:

- The client's brand is **secondary** — SGC's identity (tokens, entity
  block) remains primary throughout the document.
- Client branding is permitted **only** in: the cover page's right-hand
  panel, and the "TO" block of the transmittal letter
  (`01-templates/comms/transmittal-letter.md`).
- **The co-branding ask is website footer only — never listing pages.**
  If a client requests their logo appear on property listing pages (e.g.
  a portal-synced listing feed), decline and reference this rule
  explicitly; this is a scope boundary, not a negotiable placement detail.
- Client colour or type never overrides SGC's token system inside body
  content — a client logo is an image asset, not a license to restyle the
  document.

Any co-branding request outside these bounds is an escalation to the
Commercial Desk, not a drafting decision.
